# Rebrand Acceptance Checks

The public rebrand is complete only when:

- public HTML titles/headers use **FutolTech Structural Lab**;
- public subtitle uses **Virtual Materials, Members & Connection Testing** or a directly equivalent approved phrase;
- formal report company identity remains **FUTOLTECH ENGINEERING AND PROJECT SYSTEMS**;
- no public UI page still presents **Native Structures** as the current product name;
- historical references may remain only where explicitly marked historical;
- repository/package/GitHub Pages URLs remain unchanged for this milestone;
- automated tests guard the product/company distinction;
- existing engineering, Chromium interaction and PDF pagination gates remain green.
