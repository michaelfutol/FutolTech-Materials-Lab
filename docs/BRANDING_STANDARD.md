# FutolTech Structural Lab — Public Branding Standard

## Product identity

**FutolTech Structural Lab**

**Virtual Materials, Members & Connection Testing**

The product name describes the engineering application. It replaces the former public-facing **Native Structures** name because the platform now covers native materials, steel sections, light-gauge products, member comparison, compression/buckling, shoring, splices, yielding, optimization, and future connection/assembly/failure-physics modules.

## Company identity

Printed engineering reports and formal company identity use:

**FUTOLTECH ENGINEERING AND PROJECT SYSTEMS**

Do not replace the company identity with the product name in formal report letterheads.

## URL/repository continuity

The existing repository and GitHub Pages URL remain unchanged during the public naming migration. Repository/package renaming is a later controlled migration after the public UI and report identity are stable.

## Legacy references

Historical documents may refer to **Native Structures**. New public UI, titles, metadata, documentation headings, and report product labels should use **FutolTech Structural Lab** unless an historical reference is explicitly required.
